# Same Page, New Design — design notes

The visible wording in `before.html` and `after.html` is intentionally identical.

1. **Visual hierarchy:** a large hero heading and small eyebrow label make the main event immediately recognizable.
2. **Card grouping:** café and coaching content sit in separate cards, making the two calls to action easier to scan.
3. **Responsive layout:** the two cards become one column on narrow screens, improving phone readability.
4. **Consistent components:** pill tags, rounded buttons and spacing create a coherent design system.
