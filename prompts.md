# Prompts used to build the Week 2 projects

## Global build prompt
Build an offline-first, privacy-conscious MVP for the specified Week 2 internship project. Use plain HTML, CSS and JavaScript unless a browser extension manifest or PWA manifest is required. Keep code readable and commented. Do not use paid APIs, external logins, analytics, or send user data to a server. Include sample data, validation, empty states, accessible labels, responsive layouts, and a README with run/test steps. Implement the stated acceptance criteria honestly; do not claim untested features work.

## Project 4 — CBT Mock Test Engine
Create a CBT exam app that loads questions from JSON, has a countdown timer, question palette, answered/unanswered/marked states, subject sections, +4/-1 marking, auto-submit, persisted answers and remaining time, and a result page with score, accuracy and time per question. Include 5 sample questions and a sample JSON question file. Persist the active attempt locally and make refresh restore it.

## Project 5 — Scribbly Notes
Create an offline note-to-notebook app with live preview, three handwriting-style options using local system fallbacks, ink and paper choices, page breaks, and export through print-to-PDF. Ensure long text flows to pages and never claim actual handwriting recognition.

## Project 7 — Bill Book
Create a mobile-first shop billing PWA with shop profile, editable item catalogue, quantity, discount, tax, correct totals, invoice history, daily total, bill image/print sharing, and UPI QR generated from the exact bill total and a user-entered UPI ID. Persist records locally. Clearly label test payments.

## Project 8 — Auto Rally
Create a touch and keyboard controlled mobile-friendly auto-rickshaw racing game with looping road, coins, obstacles, power-up, three laps, timer, sound toggle, and locally saved best time. Make it work offline as a PWA.

## Project 10 — Job Clipper
Create a Chrome Manifest V3 extension with a popup to capture job title/company/deadline/link from the current page (best effort), manual editing, Saved/Applied/Interview/Result kanban stages, deadline reminders, search and CSV export. Persist data in chrome.storage.local.

## Project 12 — Chat Saver
Create a Chrome Manifest V3 extension that extracts chat messages from supported AI chat pages, allows selection, and exports Markdown or print-to-PDF while preserving headings, lists, tables and code blocks as far as the page DOM allows. Keep all processing local.

## Project 16 — Your Own Skill
Create a reusable /viva skill that reads supplied notes, asks one question at a time, waits for the answer, gives feedback, tracks a score, and ends with a revision list. Include instructions and test cases for a fresh session.

## Project 17 — Same Page, New Design
Create a plain original landing page and a redesigned version with exactly the same wording. Make the redesign responsive and document at least three design changes and why they help.
