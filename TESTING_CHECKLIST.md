# Week 2 testing checklist

Record date, browser/device, result, and screenshot filename for each check.

## Section A — Web Tools
### Project 4 CBT Mock Test Engine
- [ ] Load the supplied sample JSON question file.
- [ ] Navigate using the question palette.
- [ ] Answer, clear, and mark a question for review.
- [ ] Confirm countdown and auto-submit.

- [ ] Verify score manually using +4 / -1.
- [ ] Confirm result includes accuracy and time per question.

### Project 5 Scribbly Notes
- [ ] Type a short note and verify live preview.
- [ ] Test all three styles, ink colours, and paper styles.
- [ ] Enter a long note and verify page flow.
- [ ] Print / Save as PDF and inspect page breaks.
- [ ] Test with Wi-Fi off after loading once.

## Section B — Phone Apps and Games
### Project 7 Bill Book

### Project 8 Auto Rally
- [ ] Play using keyboard and touch controls.

- [ ] Check coins, obstacles, and power-up.

- [ ] Restart and verify best time persists.
- [ ] Test in airplane mode on a phone.
